# V2-Projeto-Iara-Games---FIAP
Nova versão do projeto que está sendo desenvolvido na FIAP

A Iara Games é um projeto acadêmico de desenvolvimento web que propõe uma 
plataforma de jogos com uma identidade visual inspirada na cultura brasileira e no folclore 
nacional. 

Objetivo 
Criar uma interface que reúna áreas de loja, biblioteca e fórum, proporcionando uma 
experiência visual organizada e intuitiva para pessoas que gostam de jogos. A proposta visual busca combinar elementos do universo gamer com referências à natureza, 
às lendas e à cultura brasileira, utilizando cores e elementos gráficos que transmitam uma 
atmosfera mística e tecnológica. 

Tecnologias utilizadas 
• HTML5 
• CSS3
